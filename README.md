# 研数 · 考研数学 AI 自学系统

根据《考研数学AI自学系统开发文档 v1.0》实现的**单人本地 MVP**：每天和 AI 老师聊着学完知识点，智能出题验收，答错的题自动进错题本并按 SM-2 间隔重复调度复习，每日任务 + 专注计时自动打卡。还能开一节**多智能体课堂**——一个老师带三个水平不同的学生，四个人各自独立调用模型。

技术形态：**纯前端多文件应用**（原生 JS + CSS，零构建、零依赖、零后端）。

---

## 快速开始

**方式一：直接双击**（推荐，完全离线可用）

打开 `index.html`，浏览器以 `file://` 协议运行，所有数据存本机浏览器 localStorage。

> 数学公式默认走 KaTeX CDN，无外网时自动降级为高亮原文显示，不影响功能。
>
> **默认接云端 API（DeepSeek）**，`file://` 下也能用——去设置页填一个 Key 就行。
> 想改用本地大模型（LM Studio / Ollama）请用方式二，`file://` 协议下浏览器会拦截对 `localhost` 的请求。

**方式二：本地服务器**

```bash
cd kaoyan-math-tutor
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

**方式三：GitHub Pages 在线部署**

本仓库可直接推送至 GitHub 并开启 GitHub Pages（Settings → Pages → Branch `main` / folder `root`），即可获得免费在线访问地址，手机/平板无需安装即用。

## 打卡规则

满足其一即视为当日打卡成功（进入连续天数与热力图统计）：

- 今日任务单 3 类任务全部完成（复习卡全评 + 新知识点全验收 + 每日一练全作答）
- 专注计时累计 ≥ 30 分钟

## AI 老师：Agent 内核

聊天页的 AI 不是"关键词匹配 + 写死模板"，而是一个带工具的 agent loop。

**它能看到什么**：每次对话前，系统从 localStorage 实时算出你的学情并注入提示词——已掌握/学习中/未开始考点数、连续打卡天数、近 7 天正确率、最薄弱的几个考点及错误次数、当前考点的作答历史与待攻克错题。模型据此决定讲什么、讲多深。

**它能做什么**（9 个工具，全部读写你的真实数据）：

| 工具 | 作用 |
| --- | --- |
| `query_weakness` | 查最薄弱的考点排行 |
| `get_mistakes` | 翻错题本（答错且尚未做对的题） |
| `pick_question` | 按知识点 + 难度加权抽题 |
| `get_node` | 读某个考点的完整正文与关联考点 |
| `search_nodes` | 按关键词检索知识树 |
| `get_progress` | 读整体进度、打卡、距考试天数 |
| `draw_graph` | **把函数画成图像直接显示**（讲极限/单调性/凹凸性/面积时） |
| `save_note` | 把总结记到考点下 |
| `mark_mastered` | 标记已掌握并生成复习卡片 |

`draw_graph` 配了一个自写的递归下降表达式求值器（**不使用 eval**），支持 `+ - * / ^`、括号、隐式乘法（`2x`、`3sin(x)`）、`sin/cos/tan/ln/log/exp/sqrt/abs` 等函数与 `pi`、`e` 常数，输出纯 SVG 曲线，无图表库依赖。

**四种老师人设**（设置页切换，同一内核的不同提示词策略）：严格督学 / 段子手 / 苏格拉底 / 应试机器。

**模型通道**（设置页分段切换，默认**云端**）：

- **云端 API（默认）**：开箱预填 DeepSeek（`https://api.deepseek.com` + `deepseek-chat`），也兼容任何 OpenAI 协议服务（Kimi / 通义 / 自建网关）。**去设置页填一个 Key 即可开聊**，无需任何本地环境。
  Key 默认只存内存，刷新页面需重填；想省事可勾「记住 Key」（写入本机 localStorage，**明文**——只在自己电脑上勾）。
- **本地模型**：设置页点"探测本机"自动扫描 LM Studio（1234）、Ollama（11434）、vLLM（8000）、llama.cpp（8081）。免 Key、离线、数据不出本机。

> 两条通道的配置**各存一份、互不覆盖**：切到云端不会清掉你的本地模型名，切回本地也不会丢掉云端 Base。

**两条健壮性保障**：

1. 模型不支持原生 `tools` 参数（本地小模型常见）时，自动降级为**文本工具协议**（` ```tool ` 代码块），不必换模型。
2. 模型完全不可用时，静默降级回内置教学引擎，聊天不中断。

> **注意**：默认的云端通道在 `file://` 下可直接用。只有改用**本地模型**时才需要方式二——`file://` 协议会拦截对 `localhost` 的请求，请在该目录执行 `python3 -m http.server 8080` 后访问 `http://localhost:8080`；LM Studio 需在 Server 设置中开启 CORS。

### 「测试连接」失败怎么排查

点「测试连接」会先问 `/models` 拿模型列表；若该地址没有这个接口，会自动改发一次**最小对话请求**来判定——因为真正要回答的问题是「能不能对话」，而不是「有没有 `/models`」。

失败提示会**按原因分开**，别混着看：

| 提示 | 含义 | 怎么办 |
| --- | --- | --- |
| `已连通，但鉴权没过` | 网络通了，Key 被拒（401/403） | 检查 Key 是否复制完整、有无多余空格、是否欠费 |
| `连不上` | 压根没建立连接 | 查网络 / 代理 / 防火墙；确认接口地址没填错 |
| `连接超时` | 建立了连接但没响应 | 云端查网络；本地看模型是否还在加载 |
| `返回的不是 OpenAI 兼容接口` | 连上了但响应不是 JSON | 接口地址应填**根地址**（如 `https://api.deepseek.com`），不要带 `/chat/completions` |
| `接口能连上，但模型列表里没有「X」` | 连得上，模型名写错了 | 按提示里列出的可用模型名改 |

> 提示语本身也**认通道**：云端地址不会让你去「启动本地推理服务」，本机地址也不会让你去「检查 API Key 余额」。

## 课堂：老师 + 三个真 agent

在知识点页进「课堂」，换一种学法。四个人**各自独立调用模型、各自有记忆、各自有工具**——不是一次批量生成出来的四段台词。

### 两种模式

| 模式 | 流程 | 适合 |
| --- | --- | --- |
| **课堂模式** | 老师分步讲知识点 → 每讲完一步，学生提问/讨论、老师答疑 → 全部讲完，老师小结 | 第一次学这个考点 |
| **讨论模式** | 老师抛一道你做错过的题 → 三个学生依次表态 → 老师点名点评谁对谁错在哪一步 | 已经学过但老是做错 |

课堂模式的「提问讨论」环节是重点：老师讲完一步，学生可以 `raise_hand` 举手，举手会**打断调度**——下一个发言的必然是老师，先答疑再继续。三个学生也会互相接话。

### 差异不是靠形容词，是靠机制

如果只在提示词里写「你是一个基础薄弱的学生」，模型会趋同——三个人说出同一种 AI 腔。真正的差异化靠三件事：

| 角色 | 系统提示里拿到什么 | 调 `look_up` 能查到什么 | 典型表现 |
| --- | --- | --- | --- |
| 学生甲（思路快） | 完整正文 + 例题 + 关联考点 | 全部 | 一针见血，爱把规律总结成一句话 |
| 学生乙（中等） | 正文 + 例题 | 正文 + 例题 | 跟得上，但爱追问"为什么" |
| 学生丙（基础薄弱） | **只有第一句定义** | **也只有第一句定义** | 口语化、用错术语、想当然 |

关键在于**第三列**：丙就算主动调工具去查资料，也只能查到那一句。这是**结构性无知**，不是演的——提示词拦不住模型"自由发挥"，但数据源可以。

丙犯的错从**你的错题本和题目干扰项**里挖，不是模型随机编的。所以他踩的坑，就是你真的会踩的坑。

### 谁决定下一个谁说话

借了 [OpenMAIC](https://github.com/THU-MAIC/OpenMAIC)（清华，36k★）的 director graph 思路，但做了成本裁剪——**先本地规则短路，只在歧义回合才问模型**：

1. 有人举手 → 老师，直接定，不问模型
2. 还有人没开过口 → 按优先级让他开口，不问模型
3. 说到量了 → 结束，不问模型
4. 都不满足 → 才调一次调度器，让它返回 `{"next": "agent_id" | "END"}`

调度器挂了也不影响上课——退回轮转，绝不因为调度失败让整节课中断。

### 记忆

每个学生只记自己的：自己说过的话（去重、上限 4 条）+ **老师点名点评到自己的那几句**。老师点评里出现「学生丙」，那句话就自动进丙的记忆。下一轮他开口时会看到「老师点评到我：……」。

### 成本

| 环节 | 调用次数 |
| --- | --- |
| 老师每次发言 | 1 次（流式） |
| 三个学生首轮 | **3 次并发**（墙钟时间等于 1 次） |
| 后续每轮学生 | 1 次 |
| 调度器 | 仅歧义回合 1 次 |
| 学生 agent loop | 上限 2 步（调工具 → 出结论） |

一场课堂模式（2 步讲授）约 **8-12 次调用**，讨论模式约 **6-8 次**。云端约 20-40 秒，用逐字打字掩盖等待。

> 想省钱就少开课堂，多用聊天页——聊天页一场只花 1-2 次。

### 学生能用的工具（白名单）

| 工具 | 作用 |
| --- | --- |
| `look_up` | 翻书查当前考点——**查到的内容受水平限制** |
| `recall_mistake` | 回忆自己做错过的题（只给题干和错次，**不给答案**） |
| `draw_graph` | 在黑板上画函数图像 |
| `raise_hand` | 举手，要求老师先答疑 |
| `pass` | 这轮不说了（弃权） |

学生**不能**标掌握、不能记笔记、不能改你的学情数据——`STUDENT_SCHEMA` 是独立白名单，跟老师的 9 个工具分开。

### 选题优先级

错过次数最多的题 → 正确率最低的考点里抽一题 → 当前考点随机一题。

## 卡片库：把一节课变成能打印的复习卡

课堂上聊完的东西，关上页面就忘了。卡片库把它压成**能揣兜里、能贴墙上**的复习卡。

课堂页点「整理成复习卡片」→ 卡片库（左侧导航也有一项，跨考点汇总）。

### 五类卡片

| 类型 | 正面 | 背面 | 从哪来 |
| --- | --- | --- | --- |
| **题目回顾** | 题干 | 答案 + 思路 | 这节课讨论的那道题 |
| **必记结论** | 结论本身 | —— | 老师最后一段小结里的编号列表；没编号就按关键词抽句 |
| **易错点** | 老师点名的原句 | —— | 老师点评里**点到学生名字**且含「错 / 混淆 / 不能」的句子 |
| **疑问解答** | 学生的问句 | 老师随后的回应 | 学生发言里的问句 + 下一个老师回合的头两句 |
| **必记公式** | 公式 | **它出现的那句话** | 题目解析、老师发言、黑板 |

必记结论优先抽**编号列表**（老师自己已经归纳过了），没有编号才退回关键词匹配——
让老师的话原样变成卡片，比我重新组织一遍可靠。

### 公式卡有一道闸

这段数据里 `$...$` 大量用于正文里的行内数学（`$\sin x$ 等价于 $x$`）。第一版直接把每个
`$...$` 都做成公式卡，结果 15 张卡里有 5 张是 `x^3/2`、`1/2`、`\sin x` 这种碎片——
**这不是公式，是句子的零件**。

现在的判据分三层，关键是**别把「符号」当成「结构」**：

1. **含等号** → 是结论式，直接认（`a^2+b^2=c^2`）
2. **含结构命令** → 是个式子（`\frac` `\lim` `\int` `\sqrt` `\sim` …）
3. **只有单个符号** → 得够长才算（`\to` `\infty` `\leq` …）

第 2、3 层还都要求**含变量**——光有数字和符号的片段不是公式。这条约束是后来补的：
`$1^{\infty}$` 由一个数字、一个上标和一个符号组成，早期版本把 `\infty` 归进结构命令，
于是这个「未定式标记」被做成了公式卡，而它的注解句跟同一节课的易错点卡**一字不差**——
印出来是两张废纸。靠长度阈值也拦不住：写成 `$1^{\infty}$` 有 11 个字符，照样漏过去。

黑板上的式子是人主动写上去的，无条件保留。

### 两道去重

规则抽取会从不同角度命中同一句话，所以出了两条去重：

- **背面不跟别处复读**：某张卡的背面如果跟别的卡的正面（或背面）是同一句，背面清空。
  清的是复读，不是删卡——卡本身还有价值。
- **公式清单不再拆卡**：如果某张卡整个就是「一串并列公式的清单」（剥掉 `$...$` 后不剩
  文字），那它列到的公式就不再单独出卡。否则「必记 2」加三个等价无穷小会变成四张卡，
  翻的时候会觉得这工具在凑数。两个约束缺一不可：**至少两个并列公式**才叫清单（整节课
  只讲一个公式时，那张结论卡也是纯公式，但公式卡不该被一起干掉）；**剥掉公式后还剩
  文字**说明有语境（「记住：…，这就是第二个重要极限」），这种卡提到的公式该单独留一张。

### 两条生成路径

| 方式 | 成本 | 特点 |
| --- | --- | --- |
| **整理成复习卡片**（默认） | **0 次调用** | 本地规则抽取，即时、离线可用、可重复跑（同内容不会重复出卡） |
| **AI 精炼** | 1 次调用 | 让模型重新组织，把易错点的「错误说法 / 正确理解」拆得更干净。会覆盖当前卡片，有确认 |

先用免费的，不满意再花那一次调用。

### 导出

- **导出 PDF** —— 调浏览器打印，在打印对话框里选「另存为 PDF」。
  A4 两栏、按类型配色、卡片带 `break-inside: avoid` 不会被分页切成两半。
  **这一步需要你在打印对话框点一下**：零依赖的纯前端拿不到浏览器的 PDF 引擎，
  而自己在 JS 里造 PDF 就得内嵌中文字体（几 MB），那会毁掉这个项目最大的优点。
- **下载 HTML** —— 一个自包含的 `.html`，样式内联、双击就能打开再打印一次，适合存档。

屏幕上的卡片、打印出来的卡片、下载的 HTML —— **同一套 HTML、同一套 CSS**（`cards.js` 里的
`CARD_CSS`，字号用 `em`，屏幕 13.5px / 打印 10pt）。所以「所见即所得」不是靠对齐两份模板，
而是根本只有一份。

> 公式在**无外网**时会退化成等宽的 LaTeX 原文（跟全站一致的降级策略）。
> 有网时 KaTeX 正常渲染。数学内容宁可显示原文，也不做有损的自动美化。
