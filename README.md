# 研数 · 考研数学 AI 自学系统

根据《考研数学AI自学系统开发文档 v1.0》实现的**单人本地 MVP**：每天和 AI 老师聊着学完知识点，智能出题验收，答错的题自动进错题本并按 SM-2 间隔重复调度复习，每日任务 + 专注计时自动打卡。

技术形态：**纯前端多文件应用**（原生 JS + CSS，零构建、零依赖、零后端）。

---

## 快速开始

**方式一：直接双击**（推荐，完全离线可用）

打开 `index.html`，浏览器以 `file://` 协议运行，所有数据存本机浏览器 localStorage。

> 数学公式默认走 KaTeX CDN，无外网时自动降级为高亮原文显示，不影响功能。

**方式二：本地服务器**

```bash
cd kaoyan-math-tutor
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

**方式三：GitHub Pages 在线部署**

本仓库可直接推送至 GitHub 并开启 GitHub Pages（Settings → Pages → Branch `main` / folder `root`），即可获得免费在线访问地址，手机/平板无需安装即用。

## 功能清单

| 模块 | 说明 |
| --- | --- |
| 仪表盘 | 今日任务单（到期复习 / 新知识点 / 每日一练）、四项统计卡、专注计时器、26 周学习热力图、连续打卡天数 |
| 知识树 | 高数 7 章 + 线代 6 章 + 概率统计 6 章共 68 个考点，按考试范围（数一/二/三）过滤，节点级掌握状态（新/学习中/已掌握） |
| 聊天学习 | 内置 AI 名师讲解：先直觉后严格、例子、追问答错点、关联考点、3 题验收评级；可配置 LLM 切换真实大模型 |
| 每日一练 | 每天 5 题，抽题策略优先"掌握度低 + 错题多的知识点"；选择/填空即时判分；每题带来源徽章（经典例题/真题改编/模拟题 + 年份） |
| 筛选练习 | 设置页按来源 / 年份 / 难度筛选题库（204 题全量），自定义单轮题量随机抽取，可随时"重新筛选" |
| 复习队列 | SM-2 四档自评（忘记/困难/记得/轻松），错题复习卡优先；到期自动出现在今日任务 |
| 错题本 | 答错自动收录，按知识点筛选，一键重练，做对后自动移出 |
| 统计 | 热力图、14 天正确率折线、三科掌握度雷达、各章正确率条形 |
| 设置 | 考试范围、每日新学量、目标考试日期、LLM 接入（Key 仅存内存）、数据重置 |

## 打卡规则

满足其一即视为当日打卡成功（进入连续天数与热力图统计）：

- 今日任务单 3 类任务全部完成（复习卡全评 + 新知识点全验收 + 每日一练全作答）
- 专注计时累计 ≥ 30 分钟

## AI 老师：内置引擎 √ / 真实 LLM 可选

- **默认内置**：基于知识树自带教学编排（讲解 → 例子 → 追问 → 关联 → 3 题验收），完全本地、无需 Key、回复始终围绕当前考点。
- **配置 LLM**：设置页填入 OpenAI 兼容 API（DeepSeek / Kimi / 通义等）的 Base URL、模型名与 Key 并"测试连接"后启用；对话走流式（SSE）回复。
  - **安全说明**：API Key 仅保存在当前页面的内存变量中，**不会写入 localStorage / 任何文件**；刷新页面需重新输入。

## 判题容错

选择题精确匹配；填空题支持：全半角与全角标点归一、`1/2` 与 `0.5` 等价、π/pi/`\pi` 互认、`x^2` 与 `x²` 归一、数值 1e-6 容差。

## 已知限制（MVP 边界）

- 无账号体系，数据跟随浏览器（换浏览器/清缓存即重置，可在设置页导出数据前先备份思路）
- 内置题库 204 题（覆盖 68 个考点、每节点 ≥2 题），含来源标注（经典例题/真题改编/模拟题 + 年份）；可在设置页按来源/年份/难度筛选练习
- 验收从当前考点加权抽 3 题（真题改编优先、难度贴近考点难度）
- 未实现 V2.0 路线图中的多设备同步、语音交互、AI 生成个性化题目（详见开发文档路线图）

## 开发文档对照

- 复习调度：开发文档 8.4.3 的降级方案即 SM-2，本实现含 EF 衰减与四档自评
- 聊天学习：文档 5.3/6 的教学流程（讲解→追问→验收）
- 在线出题判题：文档 8.1.1 选择题 + 8.1.2 填空题 + 归一化判题
- 每日打卡统计：文档 5.1 仪表盘与 8.6 统计
- 题库来源标注：文档 7.2 出题引擎——字段 `sourceType` / `sourceYear` / `source`

## 技术栈

- 前端：原生 JavaScript（ES5 兼容）+ 原生 CSS
- 数学公式：KaTeX（CDN 加载，离线自动降级）
- 图表：纯 SVG + CSS 动画，无图表库依赖
- 数据存储：localStorage（浏览器本地持久化）
- 零构建、零 npm 依赖，任何浏览器打开 `index.html` 即可运行
